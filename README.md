# cloud-resume-challenge
Front-End Development Process
Used ChatGPT as a learning assistant and guide throughout the creation of the front-end portion of my Cloud Resume Challenge project.
Built the resume website iteratively by developing each component step-by-step rather than attempting to create the entire solution at once.
Focused on understanding the purpose and relationship between the core front-end technologies:
HTML for structure and semantic content.
CSS for styling and presentation.
JavaScript for future interactivity and functionality.
Followed a continuous improvement approach by reviewing, testing, identifying issues, and making adjustments as problems were discovered.
Used an iterative feedback process to refine the project structure, correct mistakes, and improve my understanding of web development practices.
Learned the importance of organising a project correctly by separating files into appropriate folders:
index.html for the website structure.
css/style.css for styling.
js/script.js for JavaScript functionality.
Practiced using Git and GitHub for version control by committing changes, correcting issues, and maintaining a structured repository.
Focused on learning the reasoning behind each step instead of only completing tasks, building confidence in troubleshooting and problem-solving.
